# 童年素材库

这里是这个项目的命根子。

代码谁都能写，但「1995 年北方农村的夏天到底有什么」这种东西，
只有真的在那儿长大的人才知道。所以素材库是开放的 —— 而且是我们最想要的贡献。

## 三种能贡献的东西

| 目录 | 是什么 | 举例 |
| --- | --- | --- |
| `regions/` | 你长大的地方长什么样 | 北方农村、南方水乡、厂区大院、县城老街 |
| `activities/` | 你小时候爱干的事 | 摸鱼、钓鱼、挖蚯蚓、摘果子、粘知了、摸知了猴、捡鸡蛋、浇菜园、抓蚂蚱、烤鹅蛋、坐炕上 |
| `terrains/` | 家门口那块地是什么 | 池塘、小河、麦田、果树林 |
| `questions/` | 一整代人的提问流 | 80/90 后的童年（1990–2005） |

## 写一份素材要多久

五分钟。复制一个现成的文件改就行，不用装环境，不用懂代码。

以加一个地域为例，复制 `regions/north-rural.js`，改这几处：

```js
export default {
  id: 'my-hometown',            // 英文小写，唯一
  name: '鄂西山区',              // 显示在选项里
  era: ['1990-2005'],
  houseKind: 'tile',
  keywords: ['鄂西', '山区', '吊脚楼', '苞谷'],   // 用户说到这些词就选中你
  description: '半山腰的木房子，屋后有片竹林，下去要走二十分钟。',
  reply: '……',                  // AI 选中之后说的那句话
  palette: { /* 地面、墙、屋顶、树叶的颜色 */ }
};
```

改完在 `regions/index.js` 里加一行 import 和一行到数组里，就完了。

## 给玩法加季节

玩法素材里可以写 `seasons`，决定它一年里什么时候能玩：

```js
export default {
  id: 'bake',
  label: '烤鹅蛋',
  seasons: ['winter'],        // 不写 = 四季都能玩
  // ...
  pickable: false             // 不进采访选项（由地域自带），可选
};
```

季节不是"禁用"，是提示。玩家在夏天点烤鹅蛋，会看到
「这个得等冬天，现在夏天还没有」—— 那句话比直接不让按更像记忆。

只有 `regions/*.js` 里标了 `multi: true` 的地域才有四季（目前是北方农村）。

## 三条硬要求

**1. 只写真的。** 不要写想象的田园牧歌。土墙、麦垛、杨树上的知了、
院门口的压水井、傍晚六点整栋楼的炒青菜味 —— 这些不浪漫但准确的细节，
才是让人一看就认出来的东西。

**2. 别架空。** 如果你写的是"知了猴天黑才出土"，那就得是真的。
玩法可以随机，事实不能编。

**3. 隐私打码。** 真实姓名、门牌号、学校全名请模糊掉。
写"我妈"不要写"张桂英"。
